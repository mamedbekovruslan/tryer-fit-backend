# Tryer-Fit Backend

Backend для фитнес-приложения Tryer-Fit, созданный с помощью **NestJS** и **TypeORM**. Приложение предоставляет API для управления пользователями и фитнес-данными.

## Описание проекта

Tryer-Fit - это фитнес-приложение, которое помогает пользователям отслеживать свои тренировки, питание и прогресс. Backend обеспечивает REST API для взаимодействия с базой данных, аутентификации пользователей и предоставления фитнес-данных.

## Функциональность

- Управление пользователями (регистрация, аутентификация, профили)
- API для получения списка пользователей
- Интеграция с PostgreSQL базой данных
- Поддержка TypeORM для ORM операций
- Проверка данных пользователей с помощью скрипта check-users.ts

## Технологии

- **NestJS** - прогрессивный Node.js фреймворк
- **TypeScript** - строго типизированный язык программирования
- **TypeORM** - ORM для работы с PostgreSQL
- **PostgreSQL** - реляционная база данных
- **Node.js** - среда выполнения JavaScript
- **Express** - веб-фреймворк (используется через NestJS)

## Установка и запуск

### Предварительные требования
- Node.js (версия >= 18.x)
- npm или yarn
- PostgreSQL (локально или удаленно)

### Установка
1. Убедитесь, что вы в директории `tryer-fit-backend`
2. Установите зависимости:
```bash
npm install
```

### Запуск приложения

#### Режим разработки
```bash
npm run start:dev
```
- Запускает сервер в режиме слежения (автоматически перезапускается при изменениях)
- Сервер запускается на `http://localhost:3001` (настроен для работы с frontend на порту 3000)
- Для остановки используйте `Ctrl+C`

#### Режим отладки
```bash
npm run start:debug
```
- Запускает приложение с поддержкой отладки
- Позволяет подключиться отладчику (например, в VSCode)

#### Режим продакшн
Сначала соберите приложение:
```bash
npm run build
```

Затем запустите собранную версию:
```bash
npm run start:prod
```

## Конфигурация

Приложение использует переменные окружения для конфигурации базы данных. Создайте файл `.env` в корне проекта:

```env
DB_HOST=localhost
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=password
DB_NAME=tryerfit
PORT=3001
```

## API

### Пользователи

#### GET /users
Получить список всех пользователей

- **Описание**: Возвращает массив всех пользователей из базы данных
- **Ответ**:
```json
[
  {
    "id": 1,
    "username": "john_doe",
    "email": "john@example.com",
    "first_name": "John",
    "last_name": "Doe",
    "created_at": "2023-01-01T00:00:00.000Z",
    "updated_at": "2023-01-01T00:00:00.000Z"
  }
]
```


## Скрипты

### Проверка пользовательских данных
Для проверки данных пользователей в базе данных можно использовать скрипт `check-users.ts`:

```bash
ts-node check-users.ts
```

Этот скрипт подключается к базе данных и выводит информацию о всех пользователях.

## Сущности

### User (Пользователь)
Основная сущность пользователя с полями:
- `id` - уникальный идентификатор (автоинкремент)
- `username` - уникальное имя пользователя
- `email` - уникальный email пользователя
- `password_hash` - хешированный пароль
- `first_name` - имя пользователя (опционально)
- `last_name` - фамилия пользователя (опционально)
- `created_at` - дата создания записи
- `updated_at` - дата последнего обновления

## Следующие шаги

Для дальнейшего развития проекта планируется:

1. **Аутентификация и авторизация**:
   - Реализовать JWT-аутентификацию
   - Добавить защиту маршрутов
   - Создать систему регистрации и входа

2. **Фитнес-функциональность**:
   - Добавить сущности для тренировок, упражнений и прогресса
   - Создать API для управления тренировками
   - Реализовать отслеживание прогресса пользователей

3. **Расширение API**:
   - Добавить CRUD операции для других сущностей
   - Реализовать фильтрацию, сортировку и пагинацию
   - Добавить валидацию входных данных

4. **Безопасность**:
   - Добавить валидацию и санитизацию входных данных
   - Реализовать защиту от частых запросов (rate limiting)
   - Обеспечить безопасное хранение паролей

5. **Документация API**:
   - Интегрировать Swagger для автоматической документации API
   - Добавить примеры запросов и ответов

Проект предоставляет надежную основу для масштабируемого фитнес-приложения с использованием современных технологий.
